## Purpose

Compose the already-open Current Production from Product truth that is already earned. This is one continuous contextual workspace, not a dashboard, a fourth durable route, a new `ProductSpace`, or a source of new Product semantics.

## Composition law

1. Preserve the existing Production name / **Current Production** context.
2. Keep quiet Back and current `ProductSpace` orientation subordinate to Production material.
3. Present **World truths**, **Characters**, then **Scenes** as sections in one continuous MAT F1 field.
4. Each section previews at most three already-derived presentation rows/items. Truncation is presentation-only; **More … are available.** exposes that additional material exists.
5. The existing **World truths**, **Characters**, and **Scenes** actions remain the explicit route into their already-adopted deeper workflows.
6. Conditional Character and Scene codes are computed from the complete authoritative presentation set before preview truncation. A viewport subset never becomes an identity scope.

## Truth and uncertainty law

- Authoritative empty World truth copy remains **There are no current world truths.**
- World replacement nonconfirmation shows **Confirmation unavailable**, last-confirmed World truths, and never promotes the submitted replacement to current truth.
- Character creation nonconfirmation shows **Confirmation unavailable**, last-confirmed Characters, and never inserts the submitted Character into the confirmed list.
- Scene nonconfirmation continues to use **Last confirmed Scenes** plus the existing Scene notice. If the last-confirmed set is empty, both overview and dedicated Scenes surfaces say **There were no last confirmed Scenes.** They do not assert **No Scenes yet.**
- After authoritative Character creation, Scene presentation rows are re-derived from the current Cast so duplicate-name Character-code disambiguation remains correct. This is presentation refresh only; it does not mutate Scene Product state.

## Responsive / interaction law

At 720×520, meaningful Production material appears in the first viewport before secondary explanatory chrome. Content remains vertically reachable without a page-level horizontal escape. Light F2 and Dark D3 communicate the same hierarchy and truth.

Existing return/focus contracts remain unchanged. Back is navigation, not Undo. Preview sections do not create Product selection, dramatic salience, current-Scene state, or lifecycle meaning.
