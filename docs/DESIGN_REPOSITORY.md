# Ensemble Design Repository

The connected Google Drive folder `Ensemble Project` is the canonical design/visual workspace.

Root: https://drive.google.com/drive/folders/1VKomZE6PSaEM9c7q22p4r_N6UY0HM2D8

## Folder structure
- 01 UI-UX Architecture
- 02 Mockups & Prototypes
- 03 Visual Identity & Artwork
- 04 Motion & Animation
- 05 Store & Marketing Assets
- 06 Research & References

## Boundary with GitHub
Google Drive owns design artifacts, visual explorations, reference imagery, high-fidelity mockups, motion studies, and production art assets during exploration/refinement.

GitHub owns implementation specifications, source code, tests, machine-readable assets actually shipped with the application, and engineering validation state.

When a Drive design becomes an approved implementation requirement, record the decision/specification in GitHub while preserving the original design artifact in Drive.
