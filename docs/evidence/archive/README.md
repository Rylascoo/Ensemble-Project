# Evidence archive

This directory contains historical evidence preserved for provenance but retired from the active evidence surface.

Archive placement does not erase or rewrite the recorded checkpoint. Evidence is moved here only after repository-reference census and authority review establish that it no longer carries current phase/checkpoint authority. Historical path references inside archived records are intentionally left as recorded; resolve those paths at the historical commit or tag named by the record when necessary.

Archived evidence may inform historical investigation, but it does not establish current phase, implementation, validation, provider, or next-action authority. `CURRENT_STATE.md` remains the sole current phase/checkpoint/validation/next-action source.

Do not move evidence back into the active surface merely because a later document wants historical context. Promotion out of this archive requires a new current role justified by repository authority.
