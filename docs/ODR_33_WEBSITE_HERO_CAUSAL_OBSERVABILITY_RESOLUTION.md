# ODR-33 — Website Hero Causal-Observability Resolution

Status: RESOLVED / DIRECTOR APPROVED
Date: 2026-09-06

Blueprint 0.1 remains frozen. This post-freeze decision does not edit ODR-01 through ODR-31.

## Question

Should the website hero artwork itself be required to make a specific earlier human author directly recoverable from the hero image, or should that authorship burden be carried by subsequent deterministic site sections while the hero carries a different level of causal meaning?

## Decision

**The website hero is not required to make one specific earlier human author directly recoverable. It should carry human presence, a changed shared condition, living consequence and altered present possibility. Exact authorship / commit causality belongs to the later deterministic causal-cycle and history sections.**

Incidental specific-authorship clarity may appear in hero art, but it is not a mandatory advancement gate.

## Basis

Design evidence established:
- Site Spine 01 already allocated exact causal explanation to later causal-cycle and history sections;
- R0 classified specific prior authorship as a partial/static boundary;
- TEO-01 and TEO-02 each recovered visible authorship through two-moment temporal comparison;
- R1/A1 later tested compression of that burden into one aftermath-only still rather than whether visual authorship was possible at all.

The approved design evidence audit lives in `Rylascoo/Ensemble-Website`:

`docs/KYMAEAN_ODR_33_HERO_CAUSAL_OBSERVABILITY_EVIDENCE_AUDIT_01.md`

## Engineering effect

None.

This decision does not alter:
- Production authority;
- Take semantics;
- atomic causal commit;
- Context composition;
- Stage architecture;
- current E0-A implementation scope.

It is a website semantic-allocation decision only.
